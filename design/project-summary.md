# Ink Perp DEX - Project Summary

## 🎯 Project Overview

The Ink Perp DEX is a comprehensive design for an onchain perpetual decentralized exchange built on Kraken's Ink blockchain. This project combines the clean, intuitive interface of Lighter with the advanced trading features of Axiom Pro, creating a professional-grade trading platform.
